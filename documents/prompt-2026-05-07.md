## สรุปลำดับการทำงาน (Prompt & Actions)

### 1. คำขอ: เริ่ม Implement ทันทีตามแผนที่วางไว้
- **Prompt:** "เริ่ม implement ทันที"
- **การดำเนินการ:**
    - สร้าง API Routes สำหรับรายงานใหม่ 7 ตัว: `daily`, `monthly`, `jobs-today`, `payment`, `service`, `technician`, `customer`
    - สร้างหน้า UI (Page.tsx) สำหรับรายงาน 8 หน้า: `daily`, `monthly`, `jobs-today`, `payment`, `service`, `technician`, `stock`, `customer`
    - ใช้เทคนิค Tabler UI, Lucide Icons (Tabler Icons), และเชื่อมต่อ API จริงทั้งหมด

### 2. คำขอ: แก้ไข Error และตรวจสอบความถูกต้อง
- **การดำเนินการ:**
    - แก้ไข Type Error ใน `jobs-today` (เปลี่ยน `brand` เป็น `carBrand`, `model` เป็น `carModel`)
    - แก้ไข Error ใน `top-customer` (จัดการเรื่อง `include` ซ้อน `select` และเปลี่ยนรูปแบบข้อมูลลูกค้าให้แสดงผลง่ายขึ้น)
    - ตรวจสอบความสมบูรณ์ด้วย `npx tsc`

### 3. คำขอ: เขียนแผน Implementation และคำอธิบายรายงานลงเอกสาร
- **Prompt:** "คุณต้องเขียน implementation plan 3 รายงานก่อนหน้าด้วย implement Menu ในระบบปัจจุบัน (adminNav.ts) — 8 รายงาน เขียนแผนแบบ # $ralph + OMX+ markdown และคำอธิบายรายงานทั้งหมดลงไว้ที่ page-reports.md"
- **การดำเนินการ:**
    - จัดทำเอกสาร `documents/page-reports.md` แบบสมบูรณ์
    - รวบรวมรายงานทั้ง 11 รายการ (8 เดิม + 3 ใหม่จากเซสชันก่อน) ไว้ในที่เดียว
    - ระบุ Workflow, แหล่งข้อมูล (API), และ UI Layout ของแต่ละหน้าอย่างละเอียด
